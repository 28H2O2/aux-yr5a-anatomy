# 奥克斯 YR-5-A 饮水机交互剖视

[在线体验：整机剖视与热水原理](https://aux-yr5a-water-anatomy.groovymesa1.chatgpt.site)

两张可交互的 SVG 图，解释上置桶温热饮水机的储水、加热、出水、反复保温与久置卫生。完整页面保存在 `index.html`，下载这一个文件即可离线打开，也可以分享项目中的二维码。

<img src="奥克斯饮水机-交互图二维码.png" width="180" alt="扫码打开两张交互图">

made by [H2O2](https://github.com/28H2O2)

单独查看内部水路图可打开 `aux-yr5a-light.html`，或打开深色版 `aux-yr5a.html`。所有 HTML 均可离线独立运行。

主视图已改为内部水路放大剖面。右侧七个步骤解释“水存在哪里”“怎样加热”“加热后怎样储存”“怎样出热水”“常温水走哪条路”“没喝完怎样反复保温”“久置时关注哪些位置”。点击“自动切换步骤”逐步演示；左右方向键切换步骤。系统减少动态效果时，页面保持静止，可用“下一步”查看各阶段，或用“手动查看下一阶段”检查温控循环。页面下方附有独立的蒸发浓缩模型、研究来源与整机位置对照。

- `aux-waterway-light.svg` / `aux-waterway.svg`：新版内部水路矢量图。
- `aux-yr5a-light.svg` / `aux-yr5a.svg`：整机剖视矢量图。
- `aux-overview-light.html` / `aux-overview.html`：原来的整机交互视图。
- `preview.png`：带部件说明的整页预览。
- `绘图依据.md`：照片、用户确认、同类专利来源及推定范围。
- `久置与反复加热-研究依据.md`：WHO、EPA、原始研究支持的结论与绘图边界。

- `奥克斯YR-5-A-整机与热水原理.html`：两张图、研究说明和嵌入的署名字体，全部在一个可离线分享的 HTML 中。
- `build.mjs` / `waterway.mjs` / `kit/`：绘图源代码、教学状态模型与 anatomy 几何工具。
- `qa/`：几何审计和局部渲染检查记录。

用户确认这是一台上置桶温热饮水机，只有热水和常温水，没有配套烧水壶。本图依据照片还原外形，依据传统温热饮水机机制绘制机内热罐与两条水路。隐藏部件的形状、位置、数量没有原厂拆机资料支持，图中的动画不代表实测流速或烧水时间。

需要 Node.js 20.10 或更高版本，不需要安装 npm 依赖。重新生成整机图、水路图和完整分享页面：

```sh
npm run build
```

本地预览：

```sh
npm run preview
```

打开终端显示的 `http://127.0.0.1:8080`。`npm run build` 会依次构建深浅主题、运行几何审计并生成 `index.html`；整机和水路图都应显示 `audit passed`。记录实体包含教学用水体和结构件，不是 YR-5-A 原厂物料数量。

已检查深浅主题、四倍局部细节、整机与放大视图、外壳遮挡、键盘选择、390px 手机布局及减少动态效果模式；几何审计和线条端点检查为零问题，浏览器控制台无错误。

`qa/actions/` 保存交互验证步骤，可配合 anatomy 技能的 `drive.mjs` 使用。绘图工具与字体的来源见 `THIRD_PARTY.md`。
