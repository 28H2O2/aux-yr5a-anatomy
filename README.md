## 红外感应小便池

独立页面为 `urinal-light.html` / `urinal.html`，支持六个工作步骤、自动切换与停止、方向键和明暗主题。系统减少动态效果时逐步手动查看。整机图与放大的阀剖面同步，水流标记按真实连接方向移动。便池盆体与存水弯切去朝向观察者的一半；阀内先导通道和补水小孔在外部展开，便于看清联系。

本图选择常见的洗冲式陶瓷便池和膜片式先导冲水阀，不对应指定实物型号。动画时长、行程和比例是教学安排；不将其作为安装尺寸、检测距离或真实冲水量。依据与部件计划见 `小便池-绘图依据.md`，纯状态模型为 `urinal-model.mjs`，绘制和动态源码为 `urinal.mjs`、`urinal-bowl.mjs`、`urinal-motion.mjs`。

## 饮水机

单独查看内部水路图可打开 `aux-yr5a-light.html`，或打开深色版 `aux-yr5a.html`。所有 HTML 均可离线独立运行。

主视图已改为内部水路放大剖面。右侧七个步骤解释“水存在哪里”“怎样加热”“加热后怎样储存”“怎样出热水”“常温水走哪条路”“没喝完怎样反复保温”“久置时关注哪些位置”。点击“自动切换步骤”逐步演示；左右方向键切换步骤。系统减少动态效果时，页面保持静止，可用“下一步”查看各阶段，或用“手动查看下一阶段”检查温控循环。页面下方附有独立的蒸发浓缩模型、研究来源与整机位置对照。

用户确认这是一台上置桶温热饮水机，只有热水和常温水，没有配套烧水壶。本图依据照片还原外形，依据传统温热饮水机机制绘制机内热罐与两条水路。隐藏部件的形状、位置、数量没有原厂拆机资料支持，图中的动画不代表实测流速或烧水时间。

需要 Node.js 20.10 或更高版本，不需要安装 npm 依赖。重新生成整机图、水路图和完整分享页面：

```sh
npm run build
```

本地预览：

```sh
npm run preview
```

打开终端显示的 `http://127.0.0.1:8080`。`npm run build` 会依次构建各物品的深浅主题、运行几何审计并生成 `index.html`；所有视图与阀门静止状态都应显示 `audit passed`。记录实体包含教学用水体和结构件，不是原厂物料数量。

已检查深浅主题、四倍局部细节、整机与放大视图、外壳遮挡、键盘选择、390px 手机布局及减少动态效果模式；几何审计和线条端点检查为零问题，浏览器控制台无错误。

`qa/actions/` 保存交互验证步骤，可配合 anatomy 技能的 `drive.mjs` 使用。绘图工具与字体的来源见 `THIRD_PARTY.md`。
